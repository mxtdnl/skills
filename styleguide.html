Communication text uses --accent-7-ink, because burnt orange is 4.32:1 on --bg-card and fails AA at body size. Its fill carries large text only, and .btn-accent in Communication is outlined.

06 · Likert

Likert scale as a radio group

Real input type="radio" elements inside a fieldset with a legend; every point has a visible label. Arrow keys move between points. The checked mark is solid --text, so it never depends on the accent's contrast. Stacks vertically on narrow screens.

07 · Choice cards

Choice cards with aria-pressed

Toggle buttons. The pressed state adds a thicker border, a filled key and a visible "Selected" label. Revealed states use the feedback colours and change the label text. Click the first group to toggle.

08 · Timer

Timer ring with pause and extend

The remaining time is always printed; the ring is supplementary. Every timed task offers Pause and Add time (WCAG 2.2.1). In the product the live region announces only at set thresholds, not every second.
